## 주요 기능

- **적 AI**: Corgi Engine의 AIBrain(상태 = 행동 + 전이 조건) 위에 커스텀 액션·결정을 추가해 일반 적과 멀티 페이즈 보스의 전투 행동을 구현했습니다.
- **보스 페이즈**: 체력 구간을 다 깎으면 보스가 기절하고, 나이프 슬래시로 블록을 깨야 다음 페이즈로 넘어갑니다.
- **무기 시스템**: 무기 타입과 사격 로직을 모듈화하여 확장이 용이하도록 설계했습니다.
- **플레이어 특수 능력**: 나이프 대시, 근접·탄환 패리, 슬래시 콤보, 갈고리, 시간 정지 등 액션 중심의 전투 시스템을 구현했습니다.
- **데이터 기반 대화 시스템**: 대화 내용을 ScriptableObject 에셋으로 관리해 코드 수정 없이 편집·재생하고, 한국어/영어를 전환할 수 있습니다.
- **밸런스 데이터 연동**: 무기·적 수치를 Google 스프레드시트에서 불러와 빌드 없이 조정할 수 있습니다.

## 주요 구현

### 1. 적 AI
- Corgi Engine의 AIBrain은 상태를 `AIAction`(행동)과 `AIDecision`(전이 조건) 컴포넌트의 조합으로 구성합니다. 그 위에 보스 패턴 교대(직전 패턴 반복 방지), 페이즈별 오브젝트 활성화, 아머 지원형 적 같은 커스텀 액션·결정을 추가했습니다.
- 보스는 체력 구간을 다 깎으면 체력이 구간 경계에 고정되고 기절(블록)합니다. 10초 안에 나이프 슬래시로 블록을 깨야 다음 페이즈로 넘어가고, 놓치면 체력 일부를 회복합니다.
- 아머가 있는 적은 피해를 아머가 먼저 흡수하고, 아머가 깨지는 순간 행동 패턴을 바꿉니다.

### 2. 무기 시스템
- 발사 방식, 탄속, 데미지 등의 수치를 Unity 인스펙터에서 즉시 조정 가능하도록 설계했습니다.
- `WeaponBox`를 활용한 씬 배치 방식으로 기획 의도에 따른 무기 배치가 자유롭습니다.

### 3. 액션 시스템
- **나이프 대시**: 벽까지의 거리에 맞춰 조준 방향으로 돌진하며 벱니다. 가까이서 맞힐수록 넉백이 커지고, 길게 누르면 적을 띄웁니다.
- **Bullet Parry**: 적의 공격 예비 동작 중에 나이프를 맞히면 기절시키는 근접 패리와, 시간을 늦추고 탄을 같은 모습으로 되받아치는 탄환 패리가 있습니다.
- **Slash Combo**: 콤보를 판정합니다.
- **BioEnerge**: 특수 능력 사용에 필요한 자원 시스템입니다
- **SpecialAbility**: 착용 무기에 따라 특수 공격을 사용 가능합니다
- **갈고리**: 지형에 걸어 스윙하거나, 적에게 걸어 끌어옵니다.
- **시간 정지**: 영역 안의 캐릭터·투사체·이동 플랫폼을 일정 시간 멈춥니다.

### 4. 대화 시스템

- 대화 내용을 ScriptableObject 에셋(`DialogueDB_Kor`, `DialogueDB_Eng`)으로 관리하여 기획자가 코드 수정 없이 편집할 수 있습니다
- `ChatEventTrigger`로 씬 내 특정 위치나 조건에서 대화를 재생합니다
- `LanguageData`를 바꾸면 대화 DB와 폰트가 함께 바뀌어 한국어/영어를 전환합니다

### 5. 밸런스 데이터

- 무기·보조 무기·플레이어 액션·적 체력과 아머를 Google 스프레드시트로 관리하고 UnityGoogleSheet로 불러옵니다
- 기획자가 시트를 고치면 빌드 없이 수치가 반영됩니다
